# ex-word

Entry for make.fun competition **"One Word From Your Ex"**
(`u-brave-eagle-12-one-word-from-your-ex-cfd97ba2`).

## Entry

**Exhausting** — 11 characters, one word.

The word an ex would use to describe you: painfully honest, self-deprecating
(the sting lands on the entrant, not the ex), instantly relatable, and it
needs no explanation.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/t1 node main.ts
```

Writes `entry.txt` containing exactly `Exhausting` (UTF-8, no trailing
whitespace beyond the printed newline on stdout; the file itself holds just
the word).
